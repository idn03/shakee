# Scope Lock

Owner: Nhat Di
Approver: Nhat Di
Status: Draft
Last updated: 2026-05-14

## In-Scope (6 features)

1. `Auth`
2. `Create a new chatroom`
3. `Join a chatroom`
4. `Chatting`
5. `Search for other users`
6. `Minimal admin` — separate `/admin` surface gated by an `is_admin` flag. Lists users; can lock/unlock an account. `CD-008`.

## Out-of-Scope 

1. Send video or other attach file format in chatroom.
2. No group chat feature, just only 1:1 direct chat.

Everything not explicitly in-scope is out-of-scope.

## Problem / Opportunity

A personal project created to improve coding proficiency and gain hands-on experience with AI agents in software development. The project focuses on building a real-time chat application to explore WebSocket communication and related APIs. It enables users to exchange real-time text messages and send images during conversations.

## Target Users

- Users:
    - They can create or join the chat room
    - Allowed to send text message and image message
    - Can find other users via nick name or phone number

- Adminstrator:
    - The person responsible for managing the application/website through the Admin Panel
    - Can create or lock user accounts
